# 学习指南格式规范 · video-tutorial-kb

学习指南与 KB.md 分工:KB.md 是给 agent 的问答索引;学习指南是给用户看的人机界面。**定位:预习(看前 5 分钟建立概念地图)+ 对照(看视频中随时翻查)**。

## 文件组织

- 所有指南集中放 `<工作目录>/guides/`,命名 `指南-PN-<集标题>.html`
- 每份指南头部带系列导航条(P1…PN 相对链接,当前集高亮)
- 单文件自包含(内联 CSS、无外部依赖、浅色主题),本地直接打开
- 系列总目录 `guides/index.html`:系列大纲 + 各集一行摘要 + 链接

## 页面结构(固定六段)

1. **Header**:系列名、集标题、元信息 chips(时长/序号/先修=上一集/难度)
2. **本集概念链**:一句话主线 + 概念流向条(A → B → C,HTML flex 链)——预习时 30 秒抓住主线
3. **时间轴大纲表**:`时间段 | 主题 | 关键概念` 三列表(与 KB.md 大纲同源,生成时直接复用)——预习主视图,对照时按时间定位
4. **概念速查卡**(对照场景核心,页面主体):本集每个核心概念一张卡,内容固定四行:
   - 术语名 + 首次出现时间码(如 `[04:35]`,来自 term_anchors)
   - UP 主原话一句(直接从 segments.json 引用,保留口语风格)
   - 一句话解释(正式术语映射,如「猜 w 和 b」=参数估计)
   - 前后关联(上一集哪里铺垫/下一集哪里回收,首尾集可省)
5. **深入理解要点**:2–4 个本集最易卡住的点,通读分段稿时识别(信号:UP 主强调「这才是关键」「很多人卡在这」,或内容本身反直觉)。每点:卡点描述 → 提示怎么理解。**只打预防针,不剧透完整解释**——详细解释留给问答回合
6. **自测清单**:5 条 checkbox 式陈述句,学完自检

## 生成规则

- 概念速查卡**必须**引用转写稿原话(带时间码),禁止凭空编「UP 主说过」
- 卡片数量 = 术语锚点数量(通常 5–15 张),按首次出现时间排序
- HTML 模板在 `assets/guide-template.html`,占位符 `{{...}}` 形式,替换规则见模板内注释
- 视觉沿用模板自带样式(浅色、卡片式),不要每次重造
- 生成后跑标签配对校验(python 正则统计 open/close),P1 曾出现标签错配

## 质量红线

- 板书公式 OCR 置信度约 60%,指南中引用公式须标注「以视频为准」或直接用转写稿文字描述
- 时间码必须是概念**首次出现**的时间(与 term_anchors 一致),不是随便哪句提到的时间
- 自测清单的陈述必须在本集内容范围内,禁止超纲
