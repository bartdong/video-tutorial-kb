# 问答协议 · 视频知识库使用规范

当用户基于已入库的视频提问时(如「激活函数那块没懂」「P3 讲的梯度是什么意思」「XX:XX 处说的那个概念」),按以下流程回答。

## 定位 → 调素材 → 扩展 → 关联

1. **定位**
   - 优先匹配 `KB.md` 的术语锚点表(术语 → 首次出现时间 → segment 编号)
   - 时间点类提问(「08:30 讲的」)直接映射到覆盖该时间戳的 segment
   - 概念类提问先查锚点;查不到再全文检索 `pN_segments.json`

2. **调原始素材**
   - 读取对应 segment 的转写原文,**必须引用 UP 主原话并标注时间码**(如 `[04:35] "…"`)
   - 概念边界不清时,读前后各 1 个 segment 确认语境
   - 涉及板书/公式/图示时,读取对应时间点的帧图(帧 idx = 时间戳/6 + 1);注意帧上公式为手写体,OCR 置信度约 60%,解释时以转写稿为准、帧图作辅助

3. **扩展解释**
   - 以 UP 主的讲法为骨架(保留其类比和叙述顺序,用户就是跟着这个视频学的)
   - 补充三层:① 原话直译(他说的是什么) ② 原理展开(为什么是这样) ③ 边界情况(什么时候不成立)
   - 遇到 UP 主口语化表述(如「猜 w 和 b」),对应出正式术语(参数估计/优化),帮助用户建立双语映射

4. **关联**
   - 指出该概念在本系列前/后集的呼应(KB.md 大纲表)
   - 适当延伸到后续视频未覆盖的进阶方向,标注「超出本视频范围」

## 回答格式要求

- 开头先给「视频里怎么讲的」(带时间码引用),再给「展开理解」
- 用户问的是某个具体困惑时,先直接回应困惑本身,不要整段复述背景
- 每次回答末尾不需要罗列素材路径;保持对话自然
